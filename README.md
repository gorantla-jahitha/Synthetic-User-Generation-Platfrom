# Synthetic Customer Research Platform

## About

This project is a Synthetic Customer Research Platform that helps users understand different types of customers using AI-generated customer personas.

The user can enter basic information about a product, target customers, and research purpose. Based on this information, the system creates different synthetic customer personas.

Users can then interact with these personas by asking questions and conducting simulated interviews. Each persona can give different responses based on its characteristics and previous interactions.

## Features

- Create synthetic customer personas
- Enter research requirements in natural language
- View customer personas
- Ask questions to personas
- Simulate customer interviews
- Compare responses from different personas
- Remember previous interactions
- Check response consistency
- Store research information

## Technologies

- ReactJS
- JavaScript
- Python
- FastAPI
- Google Gemini
- MongoDB

## Purpose

The main purpose of this project is to make customer research easier by allowing users to explore different customer perspectives through AI-generated synthetic customers.
